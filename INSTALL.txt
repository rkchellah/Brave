# Brave — Installation Guide

Windows only. The MetaTrader5 Python package has no Linux or macOS build.

---

## Prerequisites

- Windows 10/11
- Python 3.9+ (3.14 works; see the Pydantic note under Troubleshooting)
- MetaTrader 5 terminal installed
- A broker account reachable from MT5 (demo until the pipeline is verified)
- Firebase project with Realtime Database enabled
- Finnhub account (finnhub.io) — free tier is enough
- DeepSeek account (platform.deepseek.com)

---

## Step 1 — Clone

```powershell
git clone https://github.com/rkchellah/Brave-trading-agent.git
cd Brave
```

---

## Step 2 — Virtual Environment

```powershell
python -m venv .venv
```

Activate it:

```powershell
& ".\.venv\Scripts\Activate.ps1"
```

You should see `(.venv)` at the start of your prompt.

**Important:** Always use the explicit python path when running scripts, so a stray global
install cannot resolve to the wrong interpreter:

```powershell
& ".\.venv\Scripts\python.exe" your_script.py
```

---

## Step 3 — Dependencies

```powershell
& ".\.venv\Scripts\python.exe" -m pip install -r requirements.txt
```

Verify:

```powershell
& ".\.venv\Scripts\python.exe" -c "import MetaTrader5, langgraph, openai, finnhub; print('deps ready')"
```

---

## Step 4 — MetaTrader 5 Terminal

1. Install and log into the MT5 terminal with your broker account
2. Tools → Options → Expert Advisors → tick **Allow Algo Trading**
3. Confirm the Algo Trading button in the toolbar is green
4. Leave the terminal running — the Python API talks to it, not to the broker directly

The bot logs into the same account the terminal uses.

---

## Step 5 — Firebase

1. Create a Firebase project at console.firebase.google.com
2. Build → Realtime Database → Create Database
3. Project Settings → Service Accounts → Generate new private key
4. Save the file as `serviceAccountKey.json` in the project root
5. Set database rules so only your UID can read and write its subtree

---

## Step 6 — Configuration

Create `config.py` in the project root (it is gitignored — never commit it):

```python
MT5_LOGIN         = 12345678
MT5_PASSWORD      = "your_password"
MT5_SERVER        = "RoboForex-Demo"

FIREBASE_DATABASE_URL = "https://your-project-default-rtdb.firebaseio.com/"
USER_ID               = "your_firebase_uid"

DEEPSEEK_API_KEY  = "sk-..."
FINNHUB_API_KEY   = "..."

EXECUTION_MODE    = "MANUAL"   # start here, switch to AUTO once verified
```

Every value can be overridden by an environment variable of the same name:

```powershell
$env:MT5_PASSWORD = "..."      # current session
setx MT5_PASSWORD "..."        # persistent
```

Verify the config parses and validates:

```powershell
& ".\.venv\Scripts\python.exe" -c "import config; print('warnings:', config.validate_config())"
```

---

## Step 7 — Seed Broker Credentials (optional)

Pushes your `config.py` broker values into Firebase so the mobile app has something to
edit. The bot falls back to `config.py` if you skip this.

```powershell
& ".\.venv\Scripts\python.exe" src/seed_mt5_config.py
```

The script refuses to overwrite an existing node without `--force`. It can be deleted once
the node exists.

---

## Step 8 — Run

```powershell
& ".\.venv\Scripts\python.exe" src/bot.py
```

Expected output:

```
INFO: INITIALIZING Brave v3.0
INFO: Firebase connected — command listener active
INFO: MT5 credentials source: Firebase | Login: 12345678 | Server: RoboForex-Demo
INFO: MT5 connected — Account: 12345678 | Balance: $350.00
INFO: Brave bot ready
INFO: Health check PASSED
INFO: Selected pairs: EURUSD, GBPUSD, XAUUSD
```

The bot starts paused. Press START in the mobile app to begin trading.

---

## Step 9 — Mobile App

```powershell
cd brave-app
npm install --legacy-peer-deps
eas build --platform android --profile preview
```

Install the APK. Update `FIREBASE_CONFIG` and `USER_ID` at the top of `App.js` to match
your Firebase project.

## Troubleshooting

**`ModuleNotFoundError: No module named 'MetaTrader5'`**
Installed into the wrong environment:

```powershell
& ".\.venv\Scripts\python.exe" -m pip install -r requirements.txt
```

**`MT5 initialize failed`**
The terminal is not running, or it is running as a different Windows user. Start MT5 and
retry — the bot makes 3 attempts before giving up.

**`MT5 login failed`**
Wrong login/password/server. Check the log line above it for which source was used
(`Firebase` or `config.py fallback`) and fix that one.

**`MT5 credentials source: config.py fallback` when you expected Firebase**
The `mt5_config` node is missing a field. All three of login, password and server must be
present and valid, or the bot deliberately falls back.

**`Account reports trading NOT allowed`**
Algo Trading is off in the terminal, or the broker disabled trading on the account.

**`UserWarning: Core Pydantic V1 functionality isn't compatible with Python 3.14`**
Known and non-blocking. Emitted by LangChain on import.

**`All markets closed — skipping`**
No symbol reported a fresh tick. Normal at weekends.

**Signal appears in the app but no order is placed**
MANUAL mode is active, or news sentiment was UNCERTAIN. Confirm the signal in the app.

---

## Notes

- MT5 must stay running while the bot runs — the Python API is a client of the terminal
- Trades are logged to `logs/trades/trades_YYYY-MM-DD.csv` and to Firebase `alerts/`
- `config.py` and `serviceAccountKey.json` are gitignored — verify before every push
